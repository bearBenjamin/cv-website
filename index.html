02. Одностраничный лендинг - Museum HTML / SASS(SCSS) / БЭМ / API Maps / JavaScript

Описание проекта: Лендинг музея Лувр

Адаптивный («резиновый») одностраничный лендинг музея Лувр с фиксированными брейкпоинтами (1920px, 1024px, 768px, 420px). Верстка семантическая и валидная. Весь функционал реализован с использованием HTML, SASS, БЭМ и JavaScript.

Интерактивность и CSS:

  • Навигация: реализована плавная прокрутка по якорям.
  • Визуальные эффекты: при наведении и клике интерактивные элементы изменяют стиль (цвет иконок, цвет фона и шрифта). В секции Visiting реализовано плавное растягивание подчеркивания заголовка на всю ширину карточки.
  • Параллакс: на сайте реализован эффект параллакс-смещения для создания глубины.

Функционал, реализованный посредством JavaScript:

  • Слайдер с репродукциями (Welcome): бесконечная карусель с навигацией через стрелки и буллеты. Слайды меняются плавно с анимацией смещения, активный буллет подсвечивается. В поле счетчика отображается номер активного слайда
  • Видео-секция: реализован бесконечный слайдер видео-роликов. При клике на Play воспроизводится видео внутри слайда. При переключении на другой слайд текущее видео автоматически останавливается, запуская новый ролик (невозможно воспроизведение нескольких видео одновременно). Навигация (стрелки, буллеты) останавливает воспроизведение. При смене слайда меняется основное видео в кастомном плеере.
  • Кастомный видеоплеер: полностью управляемый JS-плеер.
    • Кнопки Play/Pause (на панели и по центру) управляют воспроизведением.
    • Прогресс-бар позволяет перематывать видео. При перетаскивании в конец видео останавливается.
    • Кнопка громкости переключает звук и меняет иконку (активная/неактивная).
    • Кнопка Fullscreen разворачивает видео и панель управления во весь экран.
  • Слайдер сравнения (Explore): реализован интерактивный ползунок «Было/Стало», который ограничен границами изображения и плавно открывает нижний слой.
  • Галерея (Gallery): реализована разовая анимация появления изображений при прокрутке (эффект «выплывания» снизу вверх).
  • Калькулятор билетов (секция Tickets):
    • Пересчет стоимости происходит при изменении количества билетов Basic и Senior.
  • Форма покупки (модальное окно):
    • Связь в форме (между информацией в модальном окне и секцией Ticket) реализована через состояние (state): при открытии модального окна подставляются текущие данные из секции Ticket страницы и наоборот. При закрытии модального окна внесенные изменения отображаются в соответствующих полях секции Ticket.
    • Валидация: проверка имени (3-15 символов), email, телефона (цифры), поля карты. При ошибках подсвечиваются границы.
    • Ограничения: выбор даты начинается с текущей, время выбирается с шагом 30 минут (с учетом текущего времени) с 9:00 до 18:00.
    • Синхронизация: поля в форме (слева) отображаются в макете билета (справа).
  • Контакты: в секцию интегрирована интерактивная карта Leaflet с маркерами.

03. Одностраничный лендинг - Drink2go HTML / SASS(SCSS) / БЭМ / noUiSlider / JavaScript

Описание проекта: Адаптивный каталог товаров

Главная страница интернет-магазина с каталогом товаров и формой фильтрации. Проект выполнен с использованием сборки Gulp. Вёрстка семантическая, написана на SCSS без использования шаблонизаторов и JS-фреймворков с соблюдением методологии БЭМ.

Адаптивность и сетка:

  • Реализован подход Mobile-First.
  • Заданы фиксированные брейкпоинты: мобильный (320px–767px), планшетный (768px–1439px) и десктоп (от 1440px).
  • Между точками перехода используется фиксированная ширина контента (без «резиновости»), при этом фоновые элементы растягиваются на всю ширину вьюпорта.
  • Реализован Sticky Footer: подвал прижат к нижней границе окна даже при малом количестве контента.

Графика и оптимизация:

  • Все изображения оптимизированы для Retina-дисплеев (ретинизация).
  • Использован векторный спрайт для иконок в шапке, преимуществах, кнопках и подвале.
  • Стилизация кастомных чек-боксов и радиокнопок.
  • Секция с картой реализована с использованием адаптивных изображений.

Интерактивность (JavaScript):

  • Мобильное меню: перекрывается поверх страницы (outside flow) и переключается при тапе.
  • Слайдер: Слайды переключаются без зацикливания, кнопки блокируются в крайних положениях. Для десктопной версии добавлена пагинация для перехода к конкретному слайду.
  • Форма фильтров и сортировки:
    • Реализован диапазонный слайдер (price range) с помощью библиотеки no-ui-slider, привязанный к полю ввода.
    • Сортировка и фильтрация на клиенте не реализованы (предполагается приход данных с сервера).
    • Данные формы отправляются асинхронно на адрес эхо-сервера.

04. Сайт приюта для животных - Cozy House HTML / SASS(SCSS) / БЭМ / JavaScript

Описание проекта: Cozy House (Многостраничный сайт)

Сайт приюта животных, состоящий из двух страниц: Main и Pets. Проект полностью семантичен, валиден и сверстан по методологии БЭМ с использованием препроцессора SCSS. Реализован подход Desktop-first с фиксированными брейкпоинтами (1280px, 768px, 320px). Контент центрирован, футер прижат к низу.

Адаптивность и верстка:

  • Реализована адаптация под планшеты и мобильные устройства.
  • Для оптимизации графики использованы ретина-изображения и векторный спрайт.

Интерактивность и JavaScript:

  • Навигация: реализована навигация между страницами. С главной страницы (Main) можно перейти на страницу животных (Pets) через ссылку в блоке Our Friends. Обратный переход на главную реализован через логотип или ссылку About the shelter в шапке.
  • Бургер-меню: реализовано на обеих страницах. При ширине экрана менее 768px меню сворачивается в иконку «бургер». По клику оно раскрывается на весь экран (overlay) и закрывается повторным кликом или кликом по соответствующему пункту меню.
  • Слайдер (страница Main): бесконечная карусель. Логика генерации предотвращает дублирование карточек внутри текущего и следующего слайда. Слайдер перестраивается без перезагрузки при изменении ширины экрана.
  • Пагинация на странице Pets:
    • Управление и навигация:
      • При перезагрузке страницы всегда открывается первая страница.
      • Кнопки > и < переключают на следующую и предыдущую страницы.
      • Кнопки >> и << осуществляют быстрый переход на последнюю и первую страницы.
      • На первой странице кнопки << и < становятся неактивными.
      • На последней странице кнопки > и >> блокируются.
      • В центре панели навигации отображается кружок с актуальным номером текущей страницы.
    • Алгоритм формирования контента:
      • При загрузке генерируется массив из 48 объектов (каждый из 8 питомцев повторяется ровно 6 раз).
      • Каждая перезагрузка страницы создает новую случайную последовательность карточек.
      • Контент страницы строго кэшируется: при возврате на ранее посещенную страницу без изменения экрана и перезагрузки, порядок и набор карточек полностью сохраняются.
    • Адаптивность и динамическая сетка:
      • Количество страниц зависит от ширины экрана: 6 страниц для 1280px, 8 страниц для 768px и 16 страниц для 320px.
      • При изменении ширины экрана (от 1280px до 320px и обратно) сетка перестраивается на лету без перезагрузки страницы.
      • При изменении размера окна базовый массив из 48 карточек не обновляется, сохраняя консистентность данных.
  • Попап: реализован на обеих страницах. Открывается при клике по карточке животного, блокирует скролл, затемняет фон. Закрытие происходит по клику на крестик или затемненную область.
  • Интерактивные контакты (Футер):
    • При нажатии на email или его иконку открывается установленный почтовый сервис.
    • При нажатии на телефон или его иконку запускается стандартный набор номера.
    • При нажатии на локацию открывается страница Google Maps с адресом в новой вкладке браузера.

05. Сервис просмотра и редактирования фотографий - Kekstagram JavaScript / Pristine.js / noUiSlider / Fetch API

Описание проекта: Кекстаграм

Современный веб-сервис для просмотра и обмена изображениями. Платформа позволяет пользователям просматривать галерею фоторабот, а также загружать, редактировать и публиковать собственные фотографии с использованием сторонних библиотек и встроенного Fetch API.

Загрузка и редактирование изображений:

  • Интерфейс формы: загрузка файла через кастомный инпут, автоматическое открытие формы с блокировкой скролла страницы (класс modal-open).
  • Управление масштабом: изменение размера фото от 25% до 100% с шагом 25% через CSS-трансформацию scale.
  • Эффекты: наложение и регулировка интенсивности фильтров (Хром, Сепия, Марвин, Фобос, Зной) с помощью библиотеки noUiSlider.
  • Управление формой: закрытие окна по кнопке или клавише Esc с полным сбросом всех измененных параметров до исходного состояния.

Валидация данных (Pristine):

  • Интегрирована сторонняя библиотека Pristine для валидации полей формы в реальном времени.
  • Хэштеги: проверка на спецсимволы, уникальность, длину (до 20 символов) и количество (не более 5 тегов).
  • Комментарии: валидация максимальной длины текстового поля (не более 140 символов).
  • UX-логика: блокировка закрытия формы по клавише Esc, если фокус находится в полях ввода хэштегов или комментариев.

Интерактив и работа с сервером:

  • Отправка формы: сетевой запрос с помощью нативного Fetch API (метод POST, тип multipart/form-data) с блокировкой кнопки отправки на время запроса.
  • Загрузка данных: асинхронное получение галереи изображений с удаленного сервера через Fetch API при старте приложения с обработкой ошибок сети.
  • Полноэкранный просмотр: открытие любой миниатюры в модальном окне с отображением лайков, описания и авторов комментариев.
  • Пагинация комментариев: порционный вывод комментариев (по 5 штук) по клику на кнопку подгрузки.
  • Фильтрация: сортировка фотографий (По умолчанию, Случайные 10, Обсуждаемые) с применением механизма Debounce (500 мс) для устранения дребезга.
